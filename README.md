# edulution-public

Public issue tracker for the [edulution](https://github.com/edulution-io) platform.

This repository does **not** contain application source code. It exists so that
users and contributors have a single place to **report bugs and request
features** for any edulution app — no matter which component the problem occurs
in.

## What belongs here

Open an issue here if you run into a problem or have an idea for **any**
edulution app or service, for example:

- Something is broken, throws an error, or behaves unexpectedly
- A feature is missing or could be improved
- Documentation is unclear, outdated, or wrong

This is the central place to report issues for the edulution platform — the
application repositories are private, so please always open your issue here. The
team will triage it and route it to the right component internally.

## Reporting a bug

Before opening a new issue:

1. **Search [existing issues](https://github.com/edulution-io/edulution-public/issues)**
   to avoid duplicates. If you find a matching one, add a 👍 or a comment with
   additional details instead of opening a new issue.
2. **Open one issue per problem** — please don't bundle several unrelated
   bugs into a single report.

A good bug report includes:

- **App / component** — which edulution app the issue occurs in
- **Version** — the edulution version you are running
- **Steps to reproduce** — a numbered list that reliably triggers the problem
- **Expected behavior** — what you expected to happen
- **Actual behavior** — what happened instead
- **Screenshots or logs** — anything that helps us understand the issue
- **Environment** — browser, operating system, or deployment details if relevant

## Requesting a feature

For feature requests, describe:

- **The problem** you are trying to solve (not just the proposed solution)
- **Who benefits** and in which situation
- **Alternatives** you have already considered, if any

## Code of conduct

Please be respectful and constructive. We want this to be a welcoming place for
everyone reporting issues and contributing ideas. By participating, you are
expected to uphold our [Code of Conduct](CODE_OF_CONDUCT.md).
