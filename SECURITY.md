# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in any edulution app or
service, report it privately through one of the following channels:

- **GitHub Security Advisories** — use the
  ["Report a vulnerability"](https://github.com/edulution-io/edulution-public/security/advisories/new)
  button in the Security tab of this repository (preferred).
- **Email** — send the details to
  [service@edulution.io](mailto:service@edulution.io).

Please include as much of the following as possible to help us understand and
resolve the issue quickly:

- The affected app / component and version
- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof of concept
- Any relevant logs, screenshots, or configuration details

We will acknowledge your report as soon as possible and keep you informed about
the progress towards a fix. Please give us reasonable time to address the issue
before any public disclosure.

Thank you for helping to keep edulution and its users safe.
